This project is made primarily with the following libraries:

- KiteUI
  - A Kotlin Multiplatform UI library.
  - Can be found at `libs-for-junie/kiteui`.
- Lightning Server
  - A Kotlin server framework.
  - Can be found at `libs-for-junie/lightning-server`.
- Readable
  - A state management library based on SolidJS.
  - Can be found at `libs-for-junie/readable`.
